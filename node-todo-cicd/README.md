This project is for deploying the Nodejs todo application using Jenkins CI/CD pipeline integration with Docker.
<br>
Either we can run this project locally using npm run start and also with CI/CD pipeline.
<br>
When we start the pipeline it'll automatically create the application Docker images and push it on DockerHub.
<br>
Also it is deployed on port 8000 that can be accessed after deploying on the remote server by adding this port on your instance security group.
